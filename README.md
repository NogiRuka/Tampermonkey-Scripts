# Tampermonkey Scripts

个人编写与维护的 Tampermonkey (油猴) 脚本集合。

## 🛠️ 工具箱 (Toolbox)

一个多功能综合辅助脚本，旨在提升特定网站的浏览体验。

### 核心功能

#### 1. 🌏 全局功能
*   **智能滚动按钮**：
    *   当鼠标移动到页面右下角区域时，自动显示「回到顶部」和「去到底部」按钮。
    *   **智能防遮挡**：自动检测模态框、弹窗和固定定位元素，避免在这些区域内错误触发。
    *   适用于所有网站。

#### 2. 🔍 特定网站优化

**Google / GayTorrents / GayTor.rent**
*   **链接新窗口打开**：强制搜索结果和列表链接在新标签页中打开，避免覆盖当前浏览进度。

**Bilibili 创作中心 (member.bilibili.com)**
*   **稿件搜索增强**：为稿件管理的搜索框添加**历史记录**功能。
*   **功能特性**：
    *   🕒 **自动记录**：每次搜索自动保存关键词。
    *   ⬇️ **下拉列表**：输入框聚焦时展示最近搜索历史。
    *   ⚡ **一键搜索**：点击历史记录项，自动填充并直接触发搜索。
    *   🗑️ **管理功能**：支持逐条删除历史记录或一键清空。
    *   🎨 **完美适配**：下拉框动态定位，挂载于 body，不受父容器样式限制。

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
