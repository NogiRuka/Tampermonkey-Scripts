## 📖 简介
**Pornolab 增强 (Pornolab Enhanced)** 是一款专为 Pornolab.net 设计的油猴脚本，旨在提升您的浏览体验。它可以在帖子列表页自动加载预览图，添加一键下载种子按钮，并提供丰富的自定义设置面板。

无论您是在查看搜索结果还是浏览分类页面，此脚本都能帮助您快速预览内容，无需逐个打开帖子。

## ✨ 功能特点
- **🖼️ 自动预览**：在帖子列表页自动抓取并显示预览图片。
- **⚡ 一键下载**：在标题旁添加直观的“下载种子”按钮。
- **⚙️ 设置面板**：
  - 支持 **中文** / **英文** 语言切换。
  - 自定义 **预览图大小**（小、中、大、原图）。
  - 自定义 **快捷键**（默认：`Ctrl+P`）唤起设置。
  - 支持设置 **在新标签页打开帖子链接**。
- **🔍 全屏查看**：点击任意预览图即可进入沉浸式全屏查看模式。
- **🎨 现代 UI**：精心设计的暗色主题设置面板，美观易用。

## 🛠️ 安装指南
1. 首先安装油猴插件 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击 GreasyFork 上的 **安装此脚本** 按钮。
3. 打开 [Pornolab.net](https://pornolab.net) 即可体验！

## 🎮 使用方法
- **查看预览**：正常浏览帖子列表，图片会自动加载。
- **下载种子**：点击标题旁的粉色“下载种子”按钮即可直接下载。
- **打开设置**：按下 `Ctrl + P`（或您设置的快捷键）打开配置面板。也可以通过油猴插件菜单点击“⚙️ 设置”。
- **全屏查看**：点击任意预览图即可放大查看。

## English Description

## 📖 Introduction
**Pornolab Enhanced** is a powerful userscript designed to improve your browsing experience on Pornolab.net. It automatically loads preview images for posts in the list view, adds a one-click torrent download button, and offers a comprehensive settings panel for customization.

Whether you're browsing search results or category pages, this script helps you quickly identify content without opening each post individually.

## ✨ Features
- **🖼️ Auto Previews**: Automatically fetches and displays preview images for torrents in the list view.
- **⚡ One-Click Download**: Adds a direct "Download Torrent" button to the post list.
- **⚙️ Settings Panel**: 
  - Toggle between **English** and **Chinese**.
  - Customize the **Preview Image Size** (Small, Medium, Large, Original).
  - Configure **Keyboard Shortcuts** (Default: `Ctrl+P`) to open settings.
  - Option to **Open links in new tab**.
- **🔍 Fullscreen Viewer**: Click on any preview image to view it in full-screen mode.
- **🎨 Modern UI**: Clean, dark-themed interface for settings and notifications.

## 🛠️ Installation
1. Install a userscript manager extension like [Tampermonkey](https://www.tampermonkey.net/).
2. Click the **Install** button on GreasyFork (or copy the script manually).
3. Visit [Pornolab.net](https://pornolab.net) to see it in action!

## 🎮 Usage
- **Preview Images**: Just scroll through the post list; images will load automatically.
- **Download**: Click the pink "Download Torrent" button next to the post title.
- **Open Settings**: Press `Ctrl + P` (or your custom shortcut) to open the configuration panel. You can also use the Tampermonkey menu command "⚙️ Settings".
- **Fullscreen View**: Click on any preview image to view it in full-screen mode.
